Single-monitor friendly

Keep your PC and console on one screen without repeatedly opening the monitor's physical input menu.

Monitor profiles

Each connected monitor can have its own discovered inputs, names, and shortcuts. Only the active profile registers its shortcuts.

Portable

Extract the release, run Monitor Buddy, complete setup once, and keep it in the Windows system tray.

DDC/CI

Monitor Buddy uses DDC/CI input control where the display exposes the required input-source capability.

Compatibility

Monitor Buddy is designed for compatible external monitors that expose DDC/CI input switching. Compatibility can vary with monitor firmware, GPU drivers, docks, adapters, KVMs, and connection paths.
