# Changelog

## v5.6 — First Stable Release

- Portable compiled Windows application
- Dedicated Monitor Buddy tray identity
- Monitor profiles
- Configurable F1–F9 input shortcuts
- Active-profile-only shortcut registration
- Monitor refresh and input scanning
- Settings UI for monitor/input configuration
- Automatic ControlMyMonitor dependency setup
- Manual EXE/ZIP dependency selection fallback
- Official dependency download fallback
- Desktop shortcut creation
- Setup launches the compiled MonitorBuddy.exe directly
- Release package validation and clean portable release structure
- Improved tray menu and application UI

## Earlier development

The project evolved from a small ControlMyMonitor/DDC/CI input-switching experiment into a complete portable Windows utility for single-monitor multi-device setups.
